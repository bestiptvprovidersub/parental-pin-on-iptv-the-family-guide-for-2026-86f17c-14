General Steps to Set a Parental PIN

The exact menu names may vary slightly by player, but the logic is the same. Below is the standard path using TiviMate 5.x — the most popular player for SubTV IP.

  1. Open TiviMate on your device.
  2. Go to the main menu and select "Settings".
  3. Choose "Parental Control" (sometimes called "Lock Settings").
  4. Turn on "Enable Parental Control".
  5. Enter a 4-digit PIN of your choice. Confirm it.
  6. Select the content you want to lock: "Adult", "All Channels", or specific categories.
  7. Exit settings. The PIN will be required when anyone tries to watch locked content.

If a Step Fails

  • Can’t find Parental Control in Settings? Check the player’s “Security” or “Lock” tab. In IPTV Smarters Pro, it is under “Settings > Lock Settings”.
  • Forgot your PIN? Most players have a “Reset PIN” option that sends a code to the email you used when activating the app.
  • Player doesn’t support parental controls? Switch to a supported player from the list above.
  • SubTV IP stream freezing? For smooth playback, set your buffer/cache to 5,000 ms and use Cloudflare DNS (1.1.1.1) to avoid ISP throttling. This does not affect the PIN lock.

Parental PIN Tips for Different Players

TiviMate 5.x

Path: “Settings > Parental Control”. You can also set a separate PIN for the settings menu itself to prevent children from changing the lock.

IBO Player Pro

Path: “Settings > Lock > Enable Lock”. Enter a 4-digit code and choose which groups or channels to protect.

IPTV Smarters Pro

Path: “Settings > Lock Settings > Enable Parental Lock”. You can lock the entire app or only specific categories.

Kodi 21

Path: “Settings > System > Add-ons > Manage Dependencies > Lock” – or use the “Parental Control” add-on from the official Kodi repository. Then set a master PIN.

Flex IPTV

Path: “Settings > Security > PIN Code > Enable”. You can restrict access by channel, category, or age rating if available.

Frequently Asked Questions

What is a parental PIN on IPTV?

A parental PIN is a numeric code you set in your IPTV player app. It locks adult channels or the entire app so that only someone who knows the code can view that content.

How do I set a parental PIN on TiviMate with SubTV IP?

Open TiviMate, go to “Settings > Parental Control”, enable it, and enter your 4-digit PIN. The lock applies to the channels you select.

Can I use the same PIN for all my IPTV players?

Yes, but you must set the PIN separately in each player app. There is no shared password across different apps, even if you use the same SubTV IP subscription.

What happens if I forget my PIN?

Most players offer a “Forgot PIN” option. This usually sends a reset link to the email address you used when activating the app. Check your inbox or spam folder.

Does SubTV IP have its own parental control?

No, SubTV IP is a streaming subscription that works with third-party players. You set the parental PIN inside the player app (TiviMate, Smarters, etc.), not inside a SubTV IP account.

Will the PIN affect streaming quality?

No. The PIN only locks or unlocks content. It has no effect on video quality, buffering, or speed. For best performance, keep your buffer at 5,000 ms and use Cloudflare DNS.

Can I lock the Settings menu too?

Yes. In TiviMate and other players, you can enable a second PIN to protect the settings screen. This prevents children from turning off the parental lock.
